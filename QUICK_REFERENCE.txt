GPIO TIMING MARKERS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pin Assignment:
  P0.2 (LED1) → Measurement window start/stop
  P0.3 (LED2) → CNN completion marker
  P2.5        → CNN boost enable

Code Pattern:
  1. GPIO HIGH  → Start measurement
  2. Execute code
  3. GPIO LOW   → Stop measurement
  4. Calculate: Energy = Power × Time

Use oscilloscope to capture:
  - Channel 1: Voltage across shunt (power)
  - Channel 2: GPIO marker (timing)

POWER CALCULATION:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Given:
  - Shunt resistance: R = 0.1 Ω
  - Supply voltage: V_supply = 3.3 V
  - Measured voltage drop across shunt: V_shunt

Calculate:
  Current:  I = V_shunt / R
  Power:    P = I × V_supply
  Energy:   E = ∫ P dt  (integrate power over time)

Example:
  V_shunt = 10 mV (measured on scope)
  I = 0.010 V / 0.1 Ω = 0.1 A = 100 mA
  P = 0.1 A × 3.3 V = 0.33 W = 330 mW
  
  If this lasts for 2 ms:
  E = 0.33 W × 0.002 s = 0.00066 J = 0.66 mJ

PRACTICAL TIPS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Turn off UART during measurement (printing costs power!)
✓ Disable LEDs if not used for markers
✓ Disable CNN clock when not in use:
    MXC_SYS_ClockDisable(MXC_SYS_PERIPH_CLOCK_CNN);
✓ Use WFI (Wait For Interrupt) instead of busy-wait loops
✓ Take 10+ measurements and average for accuracy
✓ Keep supply voltage constant (use regulated supply, not USB)
✓ Measure at room temperature (power varies with temp)
✓ Use proper ground connections (minimize ground loops)

BATTERY LIFE ESTIMATION:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Example: KWS20 application
  - 1 inference per second
  - Energy per inference: 0.31 mJ
  - Idle power (sleep): 7 mW
  - Battery: 300 mAh @ 3.7V = 1110 mWh = 3996 J

Calculation:
  Active time: 15 ms (inference)
  Idle time:  985 ms (sleep)
  
  Energy per second:
    Active: 0.31 mJ × 1 = 0.31 mJ
    Idle:   7 mW × 0.985 s = 6.9 mJ
    Total:  7.21 mJ/s = 7.21 mW average
  
  Battery life:
    3996 J / 7.21 mW = 554,000 seconds
                     = 9,233 minutes
                     = 154 hours
                     = 6.4 days

Improve battery life:
  1. Use lower power sleep modes (UPM: 0.3 mW → 100+ days!)
  2. Reduce inference frequency
  3. Optimize model (smaller = faster = less energy)
  4. Use RISC-V for simple tasks (lower power than ARM)

TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Power too high
  → Check if UART is printing (disable for measurement)
  → Check if CNN clock is always enabled
  → Check if peripherals (I2C, SPI, etc.) are enabled
  → Check if using busy-wait instead of WFI

Problem: Can't see CNN vs ARM power
  → Use GPIO markers + timing correlation
  → Put ARM in sleep during CNN inference
  → Subtract baseline idle power

Problem: Noisy measurements
  → Use twisted pair for oscilloscope leads
  → Add oscilloscope averaging (16x-64x)
  → Check ground connections
  → Shield measurement leads

Problem: Results don't match expected
  → Verify clock configuration (100MHz vs 60MHz)
  → Check supply voltage (should be 3.3V)
  → Verify shunt resistor value
  → Check if CNN boost is enabled
  → Ensure proper timing (don't include UART delays)
